الموسوعة العُمانية — تجهيز النشر الثابت

لا يحتاج الموقع إلى إطار عمل أو تثبيت حزم.

1. من مجلد المشروع شغّل:
   node scripts/build.mjs
   node scripts/check.mjs
   node scripts/check-motion.mjs
2. عاين النسخة محليًا قبل النشر:
   python3 -m http.server 8000
   ثم افتح http://localhost:8000/dist/
3. على Vercel اختر Other، وأمر البناء node scripts/build.mjs، ومجلد الإخراج dist.
4. على استضافة ثابتة أخرى استخدم محتويات dist مع بقاء data وassets داخل الجذر المنشور.
5. تعمل الروابط النسبية أيضًا داخل مسار مشروع GitHub Pages.

النشر والرفع إلى GitHub يتمان بواسطة مالك المشروع؛ هذه التعليمات لا تنفذ أي نشر.
